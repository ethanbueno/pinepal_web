# Guide photos

The web Guide shows one photo per disease from this folder, the same photos as
the mobile app's Guide tab (pinepal_mobile/assets/images/diseases). Use exactly
these names:

| File | Disease |
|---|---|
| healthy.jpg | No Disease Detected |
| crown_rot.jpg | Crown Rot |
| fruit_rot.jpg | Fruit Rot |
| fruit_fasciation.jpg | Fruit Fasciation |
| mealybug_wilt.jpg | Mealybug Wilt of Pineapple |
| multiple_crown.jpg | Multiple Crown |

A missing file shows a plain placeholder. Keep each photo around 1000 px wide.
